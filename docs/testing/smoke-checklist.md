# Post-release smoke checklist (P0)

Run after every release on the live site with the demo tenant MediCore Demo Hospital. Any fail = file a bug with label `bug` + `severity:high` and `qa`.

- [ ] **XT-006** Unauthenticated API (anonymous): expect 401 — [details](https://github.com/kakani-dev/hospital-management-system/blob/main/docs/testing/cross-tenant-isolation.md#xt-006)
- [ ] **STF-007** Role matrix: menus per role (all roles): expect Menus exactly match ROLE_PERMISSIONS (e.g., accountant sees only earnings + read-only ops) — [details](https://github.com/kakani-dev/hospital-management-system/blob/main/docs/testing/staff-roles.md#stf-007)
- [ ] **SIG-002** Repeat signup with an already-registered email is blocked (anonymous): expect HTTP 409, problem code "email_registered"; no new request row — [details](https://github.com/kakani-dev/hospital-management-system/blob/main/docs/testing/tenant-signup.md#sig-002)
- [ ] **WIZ-001** First admin completes setup wizard (tenant_admin): expect Wizard completes and lands on home — [details](https://github.com/kakani-dev/hospital-management-system/blob/main/docs/testing/setup-wizard.md#wiz-001)
- [ ] **PAT-001** Register new patient (receptionist): expect MRN assigned by server; patient shows age — [details](https://github.com/kakani-dev/hospital-management-system/blob/main/docs/testing/patients.md#pat-001)
- [ ] **PAT-003** ABHA number unique per tenant (receptionist): expect 409 conflict; unique index patients_tenant_abha_key — [details](https://github.com/kakani-dev/hospital-management-system/blob/main/docs/testing/patients.md#pat-003)
- [ ] **DOC-001** Doctor sees only own queue/appointments (doctor): expect Only doctor 1's patients — [details](https://github.com/kakani-dev/hospital-management-system/blob/main/docs/testing/doctor-scoping.md#doc-001)
- [ ] **DOC-004** Doctor cannot see billing (doctor): expect Blocked; menu hidden — [details](https://github.com/kakani-dev/hospital-management-system/blob/main/docs/testing/doctor-scoping.md#doc-004)
- [ ] **APT-001** Book new consult (receptionist): expect Booked; default fee ₹500, 30 min — [details](https://github.com/kakani-dev/hospital-management-system/blob/main/docs/testing/appointments-visit-types.md#apt-001)
- [ ] **APT-002** Free follow-up within 7 days of new consult (receptionist): expect Follow-up fee ₹0 — [details](https://github.com/kakani-dev/hospital-management-system/blob/main/docs/testing/appointments-visit-types.md#apt-002)
- [ ] **QUE-001** Check-in creates queue entry and draft consult bill (receptionist): expect Queue entry waiting; draft bill with consult line at visit fee — [details](https://github.com/kakani-dev/hospital-management-system/blob/main/docs/testing/check-in-queue.md#que-001)
- [ ] **QUE-002** Double check-in (receptionist): expect "appointment already checked in"; one bill only — [details](https://github.com/kakani-dev/hospital-management-system/blob/main/docs/testing/check-in-queue.md#que-002)
- [ ] **BIL-001** Intra-state bill splits CGST/SGST (billing): expect CGST 9% + SGST 9%; odd paise to CGST — [details](https://github.com/kakani-dev/hospital-management-system/blob/main/docs/testing/billing-gst.md#bil-001)
- [ ] **BIL-002** Inter-state bill uses IGST (billing): expect All tax on IGST, CGST/SGST 0 — [details](https://github.com/kakani-dev/hospital-management-system/blob/main/docs/testing/billing-gst.md#bil-002)
- [ ] **BIL-004** Healthcare consult exempt (SAC 9993) (billing): expect Zero GST on consult line; shown as exempt — [details](https://github.com/kakani-dev/hospital-management-system/blob/main/docs/testing/billing-gst.md#bil-004)
- [ ] **PAY-001** Collect cash in open counter session (billing): expect Receipt issued; bill paid — [details](https://github.com/kakani-dev/hospital-management-system/blob/main/docs/testing/payments.md#pay-001)
